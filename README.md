# Rubik's Cube Solver Growth Audit

**Live → https://eddieatadapty.github.io/jedy-flow-rebuild/**

Five ideas to turn more Rubik's Cube Solver users into subscribers, each built into a clickable version of Rubik's Cube Solver's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Solve their first cube before the price | +10–20% CR to purchase |
| 02 | Ask one thing, name the paywall after it | +10–15% CR to purchase |
| 03 | Put “No ads” first in Pro | +3–8% CR to purchase |
| 04 | Show both plans, say when each renews | +5–10% CR · ARPU +3–8% |
| 05 | Catch the people who close it | +5–10% ARPU from paywall closers |

Every price, rating and feature comes from Rubik's Cube Solver's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Rubik's Cube Solver. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
